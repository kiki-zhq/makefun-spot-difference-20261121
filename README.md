Three original hand-drawn scenes — a moonlit bakery, a firefly garden, and a cosy book nook — each with 7 fair differences hiding between two near-identical pictures. Click a difference on either side to circle it on both, with a counter of how many remain, a timer, score, hints, and WebAudio chimes. All art is drawn in code (SVG); nothing is copied from any commercial game.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Or open `game/index.html` directly in a desktop browser. No build step, no network, no tracking.

Keys: H hint · R restart scene · 1/2/3 switch scene · N next scene · M mute.
